# Naturalness pass (gemini-3-flash-preview) — numbers

Overall, the number system and classifiers are used correctly. However, the most significant issue is **politeness**. In Thai culture, speaking to a stranger or shop owner without the polite particles **ครับ (khráp)** or **ค่ะ (khâ)** sounds blunt and potentially rude. I have also flagged a few instances where textbook demonstratives (*nîi*) should be replaced with more natural spoken forms (*an níi*).

| Line (copy the Thai exactly) | Why a native wouldn't say it | Natural version (Thai + romanization + English) | New words needed |
| :--- | :--- | :--- | :--- |
| เอาสอง | To a friend or shopkeeper, it's missing a classifier and a polite particle. Without them, it sounds like a command. | **เอาสองอันครับ/ค่ะ** (ao sɔ̌ɔng an khráp/khâ) - I'll take two. | ครับ (khráp - male), ค่ะ (khâ - female) |
| นี่แพง | "นี่" (nîi) as a standalone subject sounds like a textbook translation. Natives use "อันนี้" (this item/this one) for objects. | **อันนี้แพง** (an níi phaeng) - This one is expensive. | none |
| นี่เท่าไหร่ | Similar to above; it's too blunt. It needs "อันนี้" and a polite particle to be used in a real shop. | **อันนี้เท่าไหร่ครับ/ค่ะ** (an níi thâo-rài khráp/khâ) - How much is this one? | ครับ/ค่ะ |
| เบอร์โทรศัพท์เท่าไหร่ | In Thai, we ask "what number" (à-rai) rather than "how much" (thâo-rài) for phone numbers. Using "how much" sounds like you are buying the number itself. | **เบอร์โทรศัพท์เบอร์อะไรครับ/ค่ะ** (bəə thoo-rá-sàp bəə à-rai khráp/khâ) - What is your phone number? | อะไร (à-rai = what) |
| เสื้อตัวนี้เท่าไหร่ | Grammatically perfect, but missing the polite particle for a real-life market situation. | **เสื้อตัวนี้เท่าไหร่ครับ/ค่ะ** (sɯ̂a tua níi thâo-rài khráp/khâ) - How much is this shirt? | ครับ/ค่ะ |
| แพง มีเงินสองร้อยบาท | Sounds like two unrelated facts. To sound natural while haggling, you'd add polite particles. | **แพงครับ/ค่ะ มีเงินสองร้อยบาท** (phaeng khráp/khâ, mii ngəən sɔ̌ɔng-rɔ́ɔi bàat) - That's expensive. I [only] have 200 baht. | ครับ/ค่ะ |
| สองร้อยบาท เอากี่ตัว | A seller would always add a polite particle to be friendly to a customer. | **สองร้อยบาทครับ เอากี่ตัวดีครับ** (sɔ̌ɔng-rɔ́ɔi bàat khráp, ao gìi tua dii khráp) - 200 baht then. How many would you like? | ดี (dii = good/indicates suggestion) |
| เอาหนึ่งตัว | Too short for a real interaction; sounds a bit cold. | **เอาหนึ่งตัวครับ/ค่ะ** (ao nɯ̀ng tua khráp/khâ) - I'll take one. | ครับ/ค่ะ |

### Notes on Vocabulary:
*   **ครับ (khráp) / ค่ะ (khâ):** These are essential. I recommend introducing these in the very first lesson of any Thai app, as they are used in almost every sentence.
*   **อะไร (à-rai):** This is the standard word for "What." Using "How much" (เท่าไหร่) for a phone number is a common beginner mistake because learners think of numbers as quantities, but Thais view the phone number as an identity/name.
